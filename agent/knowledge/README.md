# Local Knowledge Folder

Add your own markdown files here to extend the agent's knowledge beyond the base skill files.

## Examples

- `current_tuition.md` — current term pricing and fees
- `intake_schedule.md` — upcoming enrollment dates and deadlines
- `local_employer_contacts.md` — specific hiring contacts in South Florida
- `financial_aid_programs.md` — current scholarships and aid offerings
- `my_notes.md` — anything you know from experience that isn't in the skill files

## Format

Use the same markdown structure as the skill files:

```markdown
# My Local Knowledge: [Topic]

## [Section Heading]
[Your content here]
```

Files in this folder are loaded as additional context for the agent and treated with the same authority as the skill files.
