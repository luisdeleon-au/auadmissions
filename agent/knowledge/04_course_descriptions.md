# Knowledge: Official Course Descriptions (CIT Courses)
## Source: Atlantis University 2026 Catalog, Volume I

---

## Programming & Operating Systems Track

### CIT 102 — Introduction to Computer Programming (3 credits)
Addresses students with little to no programming experience. Introduces fundamental concepts of problem solving and procedural programming. Programming language used: **Python** (most popular general-purpose programming language). Zero experience required.

### CIT 105 — Programming Practice (3 credits)
Follows up on CIT 102. Covers implementation of common data structures (lists, stacks, files) and frequently used algorithms (searching, sorting, image processing) using Python. Covers software design principles and algorithm complexity analysis.
**Certification prep:** PCEP – Certified Entry-Level Python Programmer (Python Institute) and with additional preparation, PCAP – Certified Associate in Python Programming.

### CIT 110 — Computer Operating Systems (3 credits)
Prepares students to manage and maintain operating systems on personal computers as entry-level IT professionals. Covers critical thinking for computer deployment decisions and customer service skills.
**Certification prep:** CompTIA A+ Certification Exam (220-802 foundation).

### CIT 225 — Management Information Systems (3 credits)
*(Described in course outline as "Management Information Systems")*
Bridges technology and business — how organizations use IT systems for planning, control, and decision-making.

## Network Technology Track

### CIT 280 — Network Design (3 credits)
Applied and practical knowledge for designing, configuring, installing, and troubleshooting hardware, peripherals, and protocols used in local area networking.
**Certification prep:** CompTIA Network+ (N10-006) — vendor neutral exam.

### CIT 281 — Network Administration and Technical Support / Cisco ICND 1 (3 credits)
Hands-on training in fundamental networking, LAN switching, routing, infrastructure services, and infrastructure maintenance.
**Certification prep:** Cisco Interconnecting Cisco Networking Devices Part 1 (100-105 / CCNA ICND1).

### CIT 282 — Advanced Network Administration / Cisco ICND 2 (3 credits)
Builds on ICND1. Covers LAN switching technologies (VLANs, STP, EtherChannels), routing protocols, WAN technologies (GRE, MLPP, PPoE, DMVPN), intermediate services.
**Certification prep:** Cisco Interconnecting Cisco Networking Devices Part 2 (200-105 / CCNA ICND2).

### CIT 283 — Networking on Azure and AWS (3 credits)
Overview of Azure and AWS networking services. Covers what solutions are available for networking, use cases for enterprise deployment, and how providers designed these products for availability and reliability.

## Cloud Technology Track

### CIT 381 — Linux Technology (3 credits)
Fundamental skills and knowledge to configure, manage, and troubleshoot Linux systems. Covers Linux system architecture, administration package, file systems, troubleshooting, and basic network security.
**Certification prep:** CompTIA Linux+ (LX0-104).

### CIT 382 — Cloud Technology Developer (3 credits)
Introduces fundamentals of cloud-based architectures with **Amazon Web Services (AWS)**. Students design and implement scalable, fault-tolerant, highly available, and secure cloud infrastructures based on business goals.
**Certification prep:** Amazon AWS Certified Architect Associate Solution Exam.

### CIT 383 — Advanced Cloud Technology Architect (3 credits)
Design of distributed applications and systems on the AWS platform. Covers migrating complex multi-level applications, scalable design across enterprise operations, and cost control strategies.
**Certification prep:** Amazon AWS Certified Solutions Professional Architect Exam.

### CIT 384 — Manage Cloud Technology Identities and Requirements (3 credits)
Focused on Microsoft's Managing Office 365 Identities and Requirements (70-346). Covers Office 365 admin center, Microsoft Exchange Online, Skype for Business Online, SharePoint Online, Office 365 ProPlus, and Azure Active Directory.
**Certification prep:** Microsoft Managing Office 365 Identities and Requirements (70-346).

### CIT 385 — Cloud Technology Compute Services (3 credits)
Deploying compute capacity in Azure and AWS. Uses AWS Lightsail, EC2, and Azure Compute Resources to deploy virtual machines, virtual servers, applications, and scale sets.

### CIT 386 — Cloud Network Design (3 credits)
Comprehensive view on network and cloud computing. Covers network management, operation, and design alongside cloud service/deployment models, implementation strategies, and application design.

### CIT 387 — IaaS: Cloud Virtualization (3 credits)
Foundational knowledge of cloud computing from a business perspective. Covers prominent service providers (AWS, Google, IBM, Microsoft), service models (IaaS, PaaS, SaaS), deployment models (Public, Private, Hybrid), and key components (VMs, Networking, Storage, CDN).

## Database Systems Track (Bachelor's)

### CIT 406 — Database Design (3 credits)
Introduction to database design using the relational model. Creating databases using MS SQL and MySQL. Covers differences between Relational vs. NoSQL databases.

### CIT 407 — T-SQL: Queries Design and Tuning (3 credits)
T-SQL (Transact Structure Query Language) — database procedural programming language extending SQL for Microsoft SQL Server. Continues CIT 406; focused on designing transactions and tuning databases for increased efficiency.

### CIT 408 — Database Management Operations & Optimization (3 credits)
Maximizing speed and efficiency of data retrieval. Covers database design, administration, and analysis methods to optimize system performance.

### CIT 410 — Non-SQL Databases (3 credits)
Databases that store data in formats other than relational tables — allows unstructured data (images, documents) to be managed. Hands-on experience with a Non-SQL database such as MongoDB.

### CIT 411 — Programming with Python (3 credits)
Assumes working knowledge of Python (builds on CIT 102/105). Covers applications including automation of information processes, web programming, image processing, and device control.

## Cybersecurity Track (Bachelor's)

### CIT 480 — Security Technology (3 credits)
Teaches skills to identify risks, participate in risk mitigation activities, and provide infrastructure, application, information, and operational security. Covers security controls for confidentiality, integrity, and availability.
**Certification prep:** CompTIA Security+ exam (SY0-401).

### CIT 481 — Security Ethical Hacking (3 credits)
Full life cycle hacking and penetration testing. Hands-on instruction in each phase: reconnaissance, scanning and enumeration, access, privilege escalation, maintaining access, covering tracks, placing backdoors.
**Certification prep:** EC Council Certified Ethical Hacking (CEH 312-50).

### CIT 482 — Security Analyst (3 credits)
Advanced penetration testing methodology with emphasis on documentation and writing penetration test reports.
**Certification prep:** EC Council Certified Safety Analyst v9 (ECSA).

### CIT 483 — Information Systems Security (3 credits)
Based on ISC2's comprehensive body of global knowledge. Covers new threats, technologies, regulations, standards, and practices for security leaders.
**Certification prep:** ISC2 CISSP (Certified Information Systems Security Professional) — foundational.

### CIT 484 — Advanced Information Systems Security (3 credits)
Final course building on all previous InfoSec classes. Advanced threats, technologies, regulations, standards, and practices. Students learn to provide security solutions to engineers and senior management using a real case study.
**Certification prep:** ISC2 CISSP exam — "in great global demand."
